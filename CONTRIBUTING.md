# 參與貢獻 / Contributing

歡迎提出問題、建議與 Pull Request。

- **問題與建議**：請用 Issue 範本（問題 / 建議）。出問題時，請附上 Retis Terminal 圖示選 **儲存問題報告** 產生的檔案。使用上的疑問請到 Discussions。
- **Pull Request**：這個儲存庫由 Retis 內部的原始碼產生，每個版本一個 commit。我們在這裡審查您的 Pull Request，把接受的修改移植回內部原始碼，並在下一個版本釋出、註明您的貢獻；因此您的 Pull Request 會被關閉而不是直接合併。
- **授權**：送出 Pull Request 即表示您同意以本儲存庫的 MIT 授權釋出您的修改。
- **安全性問題**：請見 [SECURITY.md](SECURITY.md)，不要在公開的 Issue 回報。

---

Issues, suggestions and pull requests are welcome.

- **Problems and suggestions:** use the issue forms (問題 / Problem, 建議 / Suggestion). When something goes wrong, attach the file from **Save Problem Report** in the Retis Terminal icon menu. For questions, use Discussions.
- **Pull requests:** this repository is generated from Retis's internal source, one commit per version. We review your pull request here, port accepted changes into that source and ship them in the next version with credit to you, so your pull request is closed rather than merged.
- **License:** by opening a pull request you agree to release your change under this repository's MIT License.
- **Security:** see [SECURITY.md](SECURITY.md); never report vulnerabilities in public issues.
