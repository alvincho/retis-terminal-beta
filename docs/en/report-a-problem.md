# Report a problem

1. From the menu-bar (Mac) or system-tray (Windows) icon choose **Save Problem Report**. The file contains no passwords, keys or local sign-in address.
2. Open a **Problem** issue at [Issues](https://github.com/alvincho/retis-terminal-beta/issues/new/choose), describe what happened and drag the file in. Reporting needs a free GitHub account; [sign up](https://github.com/signup) if you don't have one.
3. Ask how-to questions in [Discussions](https://github.com/alvincho/retis-terminal-beta/discussions).

Report security problems privately; see [SECURITY.md](../../SECURITY.md).
