# Report a problem

1. In Retis Terminal's sidebar choose **New Data Browser**. Under **On this computer** at the top, choose **Retis MAS Manager**, then **Open Retis MAS Manager**.
2. At the top of Retis MAS Manager choose **Problem report**. It saves a `report-<time>.zip` file on this computer and shows where. The report contains no passwords or keys.
3. Open a **Problem** issue at [Issues](https://github.com/alvincho/retis-terminal-beta/issues/new/choose), describe what happened and drag the file in. Reporting needs a free GitHub account; [sign up](https://github.com/signup) if you don't have one.
4. Ask how-to questions in the [**Questions** category of Discussions](https://github.com/alvincho/retis-terminal-beta/discussions/categories/%E4%BD%BF%E7%94%A8%E5%95%8F%E9%A1%8C-questions). For something Retis Terminal could do better, open a **Suggestion** at [Issues](https://github.com/alvincho/retis-terminal-beta/issues/new/choose).

**If Retis Terminal won't open:** a "Retis Terminal couldn't start" window appears. On a Mac, choose **Save Problem Report**; Finder then shows the saved report. On Windows, choose **No**; File Explorer then shows the saved report. Then report it as in step 3, with the report.

Report security problems privately; see [SECURITY.md](../../SECURITY.md).
