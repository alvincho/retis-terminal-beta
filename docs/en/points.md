# Points

Points measure compute and data use on tw-001. They have **no cash value** and are free during the beta.

| | Points |
| --- | --- |
| New account | 1,000 |
| 1st of each month (Taiwan time) | topped up to 1,000 (never reduced) |
| Create a strategy | 1 |
| Stop a strategy | 0 |
| One price refresh | 1 |
| Each paper-trading step | 10 (about 300 an hour at the default) |
| Taiwan Semiconductor Watch quotes and news | 0 |
| One analyst comment on a news item | set by each analyst, at most 5 |

Your balance and history are in **Terminal settings**. When points run out, the paid action pauses until the next top-up.
