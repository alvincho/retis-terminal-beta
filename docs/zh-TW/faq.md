# 常見問題

## Mac 無法打開

如果 macOS 說「無法打開，因為無法驗證開發者」，請到 **系統設定 → 隱私權與安全性**，在下方找到 Retis Terminal，按 **強制打開**（或 **仍要打開**）。只有第一次需要。

## Windows 已保護您的電腦

如果出現「Windows 已保護您的電腦」，按 **其他資訊** → **仍要執行**。只有第一次需要。

## 收不到驗證信

請看垃圾郵件匣。幾分鐘後仍沒收到，在 Retis Terminal 的登入畫面按 **重新寄送確認信**。

## 瀏覽器分頁關掉了怎麼辦？

點選單列（Mac）或系統匣（Windows）的 Retis Terminal 圖示 → **開啟**。

## 我的資料存在哪裡？

工作區、版面與保留的結果存在您的電腦上。tw-001 只保存帳號、點數與使用權紀錄。請看 [隱私](../../legal/PRIVACY.zh-TW.md)。

## 價格資料從哪裡來？

- 「台灣半導體觀察」的 **台灣股票報價** 來自證交所與櫃買中心，經由 tw-001 提供，不扣點。
- **歷史價格**（走勢圖、回測、模擬交易）、**新聞** 與 **公司資料** 來自在您電腦上執行的 [本機 yfinance](local-yfinance.md)，或您以自己金鑰加入的資料來源，例如富果或 FinMind。新聞只來自本機 yfinance。

## 為什麼 tw-001 不再提供 yfinance？

Yahoo 提供的財經資料供個人使用，Retis 不提供也不轉發這些資料。從 0.1.5-beta 起，yfinance 改在您自己的電腦上以 [本機 yfinance](local-yfinance.md) 執行，由您自己讀取資料。請在 Retis MAS 管理員安裝一次即可。您保留的策略會自動改用它。

## 需要輸入券商或資料商的密碼嗎？

不需要。測試版只用公開資料做模擬交易。若您有 Fugle 或 FinMind 的 API 金鑰，可以在 **終端設定 → 資料來源** 輸入，金鑰只存在您的電腦，只會直接送到該資料商。還沒有富果金鑰，可參考[富果行情 API 方案](https://developer.fugle.tw/docs/pricing/?utm_source=attas&utm_medium=docs&utm_campaign=attas_pricing)（合作推廣連結）。

## 我要的資料來源不在清單上怎麼辦？

您可以要求加入任何資料來源。若 **終端設定 → 資料來源** 沒有列出您要的資料來源，請寫信到 [datasources@retis.ai](mailto:datasources@retis.ai)，寫下資料商名稱與需要的資料（例如市場、商品或欄位）。請不要在信中附上金鑰。

## 會真的下單嗎？

不會。測試版只做模擬交易。
