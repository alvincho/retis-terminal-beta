# 第一次使用

1. **選擇語言。** Retis Terminal 第一次開啟時會問您要用哪種語言。
2. **登入 tw-001。** 按 **登入 tw-001-olive-canyon.retis.ai**（按鈕上是 tw-001 的網址），瀏覽器會在新分頁打開 tw-001 網站：
   - 還沒有帳號：按 **建立帳號**，填 email 與密碼，再到信箱點驗證連結（找不到信請看垃圾郵件）。
   - 已有帳號：直接登入。
   - 回到 Retis Terminal，幾秒內就會顯示已登入。您的電腦會自動取得使用權，不需要等人核准。
3. **台灣半導體觀察與策略監看已經開好。** 第一次登入時，Retis Terminal 會先打開「台灣半導體觀察」：五檔台灣半導體股票的報價、走勢圖、新聞與公司資料，看報價與新聞不用點數。想聽分析師對某則新聞的看法，可以請分析師評論，這會用點數（只有您按下才會扣）。「策略監看」開在它後面。
4. **試用範例。** 點一下「策略監看」，按 **試用範例：2330.TW / 2303.TW 配對交易**，再按 **重新整理**，就會看到兩檔股票的最新價格。建立範例用 1 點，之後每次更新價格也用 1 點。

您一開始有 **1,000 點**，每月 1 日（台灣時間）會補足到 1,000 點。請看 [點數說明](points.md) 與 [策略監看入門](strategy-monitor.md)。

## 之後再打開

雙擊 Retis Terminal（或點選單列／系統匣圖示 → **開啟**），會回到您上次的工作區，不需要再登入。
