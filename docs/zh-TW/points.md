# 點數說明

點數是 tw-001 上計算與資料的用量單位，**沒有現金價值**，測試期間免費提供。

| 項目 | 點數 |
| --- | --- |
| 新帳號 | 送 1,000 點 |
| 每月 1 日（台灣時間） | 補足到 1,000 點（超過 1,000 點的不會減少） |
| 建立策略 | 1 |
| 停止策略 | 0 |
| 重新整理一次價格 | 1 |
| 模擬交易執行中的每一步 | 10（預設約每 2 分鐘一步，一小時約 300 點） |
| 台灣半導體觀察的報價與新聞 | 0 |
| 請分析師評論一則新聞 | 依分析師而定，最多 5 點 |

在 **Terminal 設定** 可以看到目前點數與使用紀錄。點數不夠時，該項操作會暫停，下個月 1 日補足後即可繼續。
