# 回報問題

1. 在 Retis Terminal 側邊欄按 **新增資料瀏覽器**。在最上方的 **這台電腦** 下選 **Retis MAS Manager**，按 **開啟 Retis MAS Manager**。
2. 按 Retis MAS 管理員上方的 **問題回報**。它會在這台電腦存一個 `report-<時間>.zip` 檔，並在畫面上顯示存放的位置。報告不含密碼與金鑰。
3. 到 [Issues](https://github.com/retis-ai-sg/retis-terminal-beta/issues/new/choose) 選 **問題 / Problem**，描述發生了什麼，並把報告檔拖進去。
   - 回報需要免費的 GitHub 帳號，沒有的話請先[註冊](https://github.com/signup)。
4. 使用上的疑問請到 [Discussions 的 **使用問題** 分類](https://github.com/retis-ai-sg/retis-terminal-beta/discussions/categories/%E4%BD%BF%E7%94%A8%E5%95%8F%E9%A1%8C-questions) 發問；希望 Retis Terminal 多做什麼或改什麼，請到 [Issues](https://github.com/retis-ai-sg/retis-terminal-beta/issues/new/choose) 選 **建議 / Suggestion**。

**Retis Terminal 打不開時：** 會跳出「Retis Terminal 無法啟動」視窗。Mac 按 **儲存問題報告**，Finder 會顯示存下的報告；Windows 按 **否**，檔案總管會顯示存下的報告。然後照第 3 步回報，附上報告。

資安問題請不要公開回報，請看 [SECURITY.md](../../SECURITY.md)。
