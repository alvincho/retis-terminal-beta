# 回報問題

1. 在選單列（Mac）或系統匣（Windows）的 Retis Terminal 圖示選 **儲存問題報告**。它會存一個檔案，裡面不含密碼、金鑰或本機登入網址。
2. 到 [Issues](https://github.com/alvincho/retis-terminal-beta/issues/new/choose) 選 **問題 / Problem**，描述發生了什麼，並把報告檔拖進去。
   - 回報需要免費的 GitHub 帳號，沒有的話請先[註冊](https://github.com/signup)。
3. 使用上的疑問請到 [Discussions 的 **使用問題** 分類](https://github.com/alvincho/retis-terminal-beta/discussions/categories/%E4%BD%BF%E7%94%A8%E5%95%8F%E9%A1%8C-questions) 發問；希望 Retis Terminal 多做什麼或改什麼，請到 [Issues](https://github.com/alvincho/retis-terminal-beta/issues/new/choose) 選 **建議 / Suggestion**。

資安問題請不要公開回報，請看 [SECURITY.md](../../SECURITY.md)。
