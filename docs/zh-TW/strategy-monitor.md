# 策略監看入門

「策略監看」讓您建立交易策略、看即時訊號、回測過去的表現，並用模擬帳戶練習下單。**只做模擬交易，不會真的下單。**

## 配對交易是什麼？

挑兩檔走勢通常很接近的股票，例如台積電（2330.TW）與聯電（2303.TW）。兩者的價差偶爾會拉開又收回。策略在價差比平常小很多時「買進價差」，回到正常時出場。

- **主要股票、參考股票：** 要比較的兩檔股票。
- **Z 分數（z-score）：** 目前價差和最近一段時間平均相比，偏離了幾個標準差。數字越低，價差越不尋常地小。
- **進場 Z 分數 / 出場 Z 分數：** 低於進場值就發出進場訊號，高於出場值就發出出場訊號。
- **計算期間：** 用最近幾個價格來算平均與標準差。

## 常用操作

- **新增策略：** 選範本（例如配對交易），填兩檔股票與價格來源，按 **建立**。價格來源通常是在您電腦上執行的 [本機 yfinance](local-yfinance.md)（不扣點）；存了富果金鑰也可選富果，並可用台指期等期貨（[富果行情 API 方案](https://developer.fugle.tw/docs/pricing/?utm_source=attas&utm_medium=docs&utm_campaign=attas_pricing)，合作推廣連結）。
- **重新整理：** 取得最新價格並重算訊號（不扣點）。
- **回測：** 用過去的價格模擬策略表現。建議先用 6 個月以內的期間。
- **啟動（模擬交易）：** 按策略頁的 **啟動**，策略會定時自動更新，每次 10 點，預設約每 2 分鐘一次（一小時約 300 點）。不用時請按 **停止**（停止不用點數）。

## 價格來源

歷史價格來自您電腦上的本機 yfinance，或您以自己金鑰加入的資料來源。兩者都沒有時，**試用範例** 與 **新增策略** 會提示：請在 Retis MAS 管理員安裝本機 yfinance，或在 **終端設定 → 資料來源** 為富果等提供歷史價格的資料來源加入您自己的金鑰。

**0.1.5-beta 以前保留的策略** 使用 tw-001 的 yfinance，它已經停止提供。Terminal 列出本機 yfinance 後，這些策略下次執行或讀取價格時會自動改用它，並顯示一則簡短的說明。和套用新設定時一樣，未平倉的模擬部位會以最新價格平倉；若價格已過期，模擬交易會被清除。原本在執行中的策略會繼續用本機 yfinance 執行。

更多說明在策略監看裡的 **使用說明**。

> 本工具僅供學習與研究，不是投資建議。過去的表現不代表未來。
