# 安全性問題回報 / Reporting a security issue

請不要在公開的 Issue 回報安全性問題。請使用 GitHub 的私下回報：在這個儲存庫的 **Security** 分頁選 **Report a vulnerability**。請附上發現的內容、重現步驟與版本（Retis Terminal 圖示選單的第一行，例如 0.1.0-beta）。我們會盡快回覆，在修正版本發布後公開說明；若您願意，會在版本說明中註明您的貢獻。

回報中請勿包含密碼、API 金鑰、含 `#local-access=` 的本機網址或他人的資料。這個儲存庫只包含 Retis Terminal 本身；tw-001 服務的安全性問題也請以同樣方式回報。

---

Please don't report security problems in public issues. Use GitHub's private vulnerability reporting: on this repository's **Security** tab, choose **Report a vulnerability**. Include what you found, how to reproduce it, and the version (the first line of the Retis Terminal icon menu, such as 0.1.0-beta). We reply as soon as we can, describe the fix publicly once the version that fixes it is released, and credit you in the release notes if you'd like.

Never include passwords, API keys, the Terminal's local address with `#local-access=`, or other people's data. This repository holds only Retis Terminal itself; please report security problems with the tw-001 service the same way.
